1. Handler `toggleLancado(item)` — marca/desmarca "lançado no portal" gravando o campo correto no doc da OS conforme o tipo do item, e sincroniza reports. MIGRAÇÃO NA GRAVAÇÃO: itens `tipo === 'mo'` de OS legada podem estar marcados só via `fat_lancado_em` antigo — ao togglar um item MO, gravar SEMPRE o campo granular novo `fat_lancado_mo_em` E limpar o legado `fat_lancado_em: null` (seguro: para seguradoras com código, `fat_lancado_em` era só o rastro do modal antigo; Tempo/Maxpar usam `fat_lancado_em` como campo real, mas geram itens `tipo 'single'`, nunca 'mo'):
```javascript
async function toggleLancado(item) {
  if (item.lancado && !window.confirm('Desmarcar este item como lançado?')) return
  const novoValor = item.lancado ? null : serverTimestamp()
  const novoLocal = item.lancado ? null : new Date()
  let payload, patchLocal
  if (item.tipo === 'mo') {
    // grava o granular e limpa o legado (migração definitiva)
    payload    = { fat_lancado_mo_em: novoValor, fat_lancado_em: null }
    patchLocal = { fat_lancado_mo_em: novoLocal, fat_lancado_em: null }
  } else if (item.tipo === 'desloc') {
    payload    = { fat_lancado_desloc_em: novoValor }
    patchLocal = { fat_lancado_desloc_em: novoLocal }
  } else {
    payload    = { fat_lancado_em: novoValor }
    patchLocal = { fat_lancado_em: novoLocal }
  }
  try {
    await atualizarOS(empresaId, item.osId, payload)
    setReports(p => p.map(r => r.id === item.osId ? { ...r, ...patchLocal } : r))
    // (patchLocal usa new Date() só para o checkbox refletir na hora; o Firestore guarda o serverTimestamp)
  } catch (e) { showToast('Erro: ' + e.message, 'error') }
}
```
