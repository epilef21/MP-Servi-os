```javascript
  function handleFotoSelect(e) {
    const files = Array.from(e.target.files)
    const novas = files.map(f => ({ file: f, preview: URL.createObjectURL(f) }))
    setFotos(prev => [...prev, ...novas])
    setErroFoto('')
    e.target.value = '' // permite re-selecionar o mesmo arquivo
  }

  function removerFoto(idx) {
    setFotos(prev => {
      const copia = [...prev]
      URL.revokeObjectURL(copia[idx].preview) // libera memória
      copia.splice(idx, 1)
      return copia
    })
  }
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Usuário → input[type=file] | Arquivo não confiável vindo do sistema de arquivos do usuário; pode ter formato inesperado, tamanho arbitrário ou conteúdo malicioso |
| Componente → Firebase Storage | Upload via SDK Firebase autenticado; a URL de download é pública por padrão |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | handleFotoSelect — accept="image/*" | mitigate | `accept="image/*"` filtra no browser; imageCompression rejeita binários não-imagem com exceção capturada pelo catch de IMG-03 — a mensagem de erro impede o upload |
| T-05-02 | Denial of Service | imageCompression — arquivos muito grandes | accept | browser-image-compression usa Web Worker; não bloqueia a UI; limite de 400KB é imposto na saída, não na entrada; usuário com arquivo corrompido vê erro em português e pode tentar novamente |
| T-05-03 | Information Disclosure | Firebase Storage URLs públicas | accept | URLs de download são longas e não-adivinháveis (UUID gerado por Date.now()); escopo da OS multi-tenant já limita acesso via Firestore rules; Storage rules fora do escopo desta fase |
| T-05-04 | Spoofing | uploadFoto path — empresas/{empresaId}/fotos/{orcamentoId} | mitigate | `empresaId` e `orcamentoId` vêm de `useEmpresa()` e `useParams()` respectivamente — ambos derivados de contexto autenticado e URL da rota, não de input do usuário |
</threat_model>
